Fix Visual Studio 2022 Associations

Stop accidental version switching and lock your project extensions to VS 2022.

What does this do?

Visual Studio 2022 is a powerful, comprehensive IDE for building large-scale software. However, Windows often defaults to opening solution and project files with newer or alternative versions if you have multiple instances installed.

This lightweight tool forces system registry overrides to bind all relevant extensions (.sln, .csproj, .vcxproj, etc.) directly to Visual Studio 2022.

Quick Start Guide

  • Download the latest release archive containing both scripts.
  • Keep run.bat and vs.ps1 together inside the same folder.
  • Right-click run.bat and select Run as administrator.
  • Follow the on-screen menu prompts to apply associations.
⚠️ DO NOT rename or separate the files into different folders, otherwise the launcher won't be able to find the PowerShell execution script.
